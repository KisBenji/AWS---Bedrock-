# Amazon Bedrock

Teljes körűen menedzselt AWS-szolgáltatás, amelyen keresztül különböző gyártók generatív AI-modelljei érhetők el API-n keresztül. Lehetővé teszi AI-alkalmazások, chatbotok és intelligens automatizálási megoldások fejlesztését saját infrastruktúra és modellek üzemeltetése nélkül.
